## 🎯 Propósito

Cada subpasta representa uma semana ou fase importante do projeto e contém:

- **CHECKLIST.md** - Tarefas realizadas (marcadas com ✅)
- **SUMMARY.md** - Resumo completo da semana/fase
- **README.md** - Overview e links importantes
- **Documentos adicionais** - Análises, consolidações, etc.
